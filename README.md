# nodejs_practice

Node.js 공부 기록 저장소

## 환경

- Node.js 24 (`.nvmrc` 참고)
- npm 11

## 실행

```bash
npm install      # 의존성 설치 (패키지를 추가한 경우)
npm start        # index.js 실행
npm run dev      # 파일 변경 시 자동 재시작 (node --watch)
```

주제별 예제는 폴더를 나눠서 작성하고 직접 실행합니다.

```bash
node 01-basics/hello.js
```

## 폴더 구조

```
.
├── 01-basics/     # 주제별 예제 폴더 (02-modules, 03-fs ... 식으로 추가)
├── index.js
└── package.json
```
